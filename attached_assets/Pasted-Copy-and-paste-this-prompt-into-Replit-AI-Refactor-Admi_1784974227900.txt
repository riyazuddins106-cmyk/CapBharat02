You are acting as a Principal Software Architect, Senior React Engineer, Senior Backend Engineer, Senior Database Architect, Senior UI/UX Engineer, and Senior QA Engineer.


# Backend Requirements

Create proper APIs.

Partner Documents

```
GET /api/admin/partners/documents
```

Returns one record per partner.

Partner Document Details

```
GET /api/admin/partners/:partnerId/documents
```

Returns every document uploaded by that partner.

Review Queue

```
GET /api/admin/documents/review-queue
```

Returns documents requiring review.

Update Review

```
PATCH /api/admin/documents/:documentId/review
```

Updates:

* Status
* Reviewer
* Reason
* Timestamp
